Promotion Name 작성 매뉴얼

ELLIS & Vendor Console · 전 국가 공통 적용 · Promotion Type / Name 표기는 영문 기준 · v1.1 · 2026-08-11

1. 한 줄 규칙

Promotion Name = [조건값만] + 환불불가 시 (NRF)

규칙설명
대분류를 반복하지 않는다부킹 리포트에 [Type]-[Name]으로 합쳐서 출력되므로 중복입니다. 30 Days Advance로 쓰고 Early Bird 30 Days로 쓰지 않습니다.
숫자를 반드시 쓴다콘솔에 입력한 값이 이름에 그대로 나타나야 합니다. 숫자 없는 이름은 사후 검증이 불가능합니다.
영문만 사용한다한글·일본어·베트남어 금지. 연박, 얼리버드, 早割 등을 쓰지 않습니다.
결합은 +로 연결앞뒤 공백을 두고 연결합니다. 30 Days Advance + Min 2 Nights
NRF는 맨 뒤에Non Refundable = Yes면 끝에 (NRF)를 붙입니다. NR, Non Refundable, 환불불가 등 다른 표기는 사용하지 않습니다.
Min. Nights = 1은 조건이 아니다이름에서 생략합니다. 60 Days Advance로 쓰고 60 Days Advance + Min 1 Night로 쓰지 않습니다.
시즌명·기획전명을 넣지 않는다단, Basic Promotion에서는 Basic Rate: Summer 2026 형태로 허용합니다.

6. 기준으로 표현할 수 없는 호텔 요청 — Vendor Remark에 기재

Promotion Name은 표준 그대로. 나머지는 전부 Vendor Remark에.

호텔이 자기 표현을 그대로 써달라고 하거나, 콘솔에 입력 필드가 없는 조건을 요구하는 경우가 있습니다. 특정 룸타입 한정, 블랙아웃 기간, 요일 제한 같은 것들입니다. 이때 Promotion Name을 바꾸지 않습니다. 표준 이름으로 등록한 뒤, Vendor Promotion Detail 화면 하단의 Vendor Remark 필드에 요청 내용을 기재합니다.

태그용도작성 예시
[NAME]호텔이 요청한 원문 명칭[NAME] Hotel requested: "여름 한정 얼리버드 30일 특가"
[COND]콘솔에 담을 수 없는 추가 조건[COND] Deluxe Twin only, Mon-Thu check-in
[EXCL]블랙아웃·제외 조건[EXCL] Blackout 2026-12-24 ~ 2027-01-02
[SRC]요청 근거·출처[SRC] Hotel email, sales manager, 2026-08-05

작성 규칙 — 한 줄에 태그 하나 · 태그는 대괄호 안 대문자 · 본문은 영문 작성, 단 호텔이 요청한 원문 명칭은 나중에 대조할 수 있도록 따옴표 안에 원어 그대로 인용 · 날짜는 YYYY-MM-DD · 기준을 벗어나는 내용이 없으면 Vendor Remark는 비워 둡니다.

✗ 잘못된 작성 — 요청을 이름에 우겨넣음

  • Type Early Bird
  • Name 여름 한정 얼리버드 30일 특가
  • Vendor Remark (비어 있음)

영문 원칙과 시즌명 금지 규칙을 모두 어기고, 30일 조건도 기계적으로 읽을 수 없게 됩니다.
